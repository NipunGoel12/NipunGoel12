A 16-bit Arithmetic Logic Unit designed using Verilog HDL with a dedicated testbench and waveform verification.

```text
          └────┬─────┘
               │
               ▼
        ┌──────────────┐
        │     ALU      │
        │ Arithmetic   │
        │ Logical      │
        └──────┬───────┘
               │
               ▼
            OUTPUT
```

**Technologies:** `Verilog HDL` `Icarus Verilog` `GTKWave` `RTL Design`
